# AI Agent Learning

A beginner-friendly Python project for learning the fundamentals of AI Agent application development.

## Project Structure

```text
ai-agent-learning/
├── main.py
├── calculator.py
├── test_calculator.py
├── git-learning.txt
├── pull-request-notes.md
└── README.md
```

- `main.py`: The main entry point of the project.
- `calculator.py`: Contains a simple addition function.
- `test_calculator.py`: Tests the addition function using pytest.
- `git-learning.txt`: Notes for learning Git.
- `pull-request-notes.md`: Notes about GitHub Pull Requests.
- `README.md`: Project documentation.

## Requirements

- Python 3.13 or a compatible Python 3 version
- pytest for running tests

## Run the Program

```bash
python main.py
```

Expected output:

```text
Hello, AI Agent!
```

## Run the Tests

Activate your project's virtual environment first, if it is not already active.

```bash
python -m pytest
```

The tests should pass if the code works as expected.

## Learning Goals

- Learn Python fundamentals.
- Practice writing and testing code.
- Understand Git and GitHub workflows.
- Build a foundation for AI Agent application development.
